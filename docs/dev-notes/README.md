# Development notes

These files are the working history of the project. They were written for the owner and the coding
agents who built InvestHepi in short rounds (v1 to v19), and they are kept as they were.

| File | What it is |
|---|---|
| [`HANDOFF.md`](HANDOFF.md) | The owner's product decisions, each round's summary (what changed, what was verified, what was not) and the open items. Coding sessions read it first. |
| [`AUDIT-v19.md`](AUDIT-v19.md) | Working notes of the v19 code audit, with file and line references from November 2026. |
| [`DESIGN-v19b.md`](DESIGN-v19b.md) | The design of the story pipeline (clustering, picking, the explain call, past events). |
| `PLAN*.md` | Design notes from early versions. Some details are out of date. |

For how the code works today, read [`CLAUDE.md`](../../CLAUDE.md) at the repository root. Some entries
mention private reports that were shared with the owner only; those links are removed.
